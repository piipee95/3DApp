# 3DApp — Costos 3D

Aplicación web colaborativa para costear productos de impresión 3D.

## Funciones
- Login/registro con Supabase.
- Workspace compartido con invitaciones.
- Productos con múltiples impresiones 3D.
- Costos directos y adicionales.
- Margen objetivo sobre precio de venta.
- IVA configurable.
- Escenarios mínimo, promo, recomendado y premium.
- Duplicar, archivar y eliminar productos.

## Publicación
Pensada para GitHub Pages desde la rama main y raíz del repositorio.
