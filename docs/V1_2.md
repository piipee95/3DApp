# KultiApp V1.2

## Funciones

- Hasta siete filamentos por impresión: nombre/material, muestra de color,
  gramos de pieza, purga y precio por kilogramo. Si el peso del slicer incluye
  purga, registrar ese peso como pieza y dejar purga en cero.
- El desglose recalcula gramos y costo de filamento automáticamente. Las
  impresiones anteriores conservan su costo manual mientras no se agreguen colores.
- Duplicación independiente de impresiones dentro del producto.
- Foto optimizada a JPEG, máximo 800 px de lado y 250.000 caracteres, guardada
  con el producto bajo las políticas existentes del workspace. La foto original
  no se sube. Las fotos HEIC dependen de la compatibilidad del navegador.
- Indicador de borrador local frente a producto guardado en la nube.
- Neto final, IVA y utilidad calculados sobre el precio redondeado.
- Cotización sin costos, márgenes ni utilidad: vista previa, impresión/PDF del
  sistema y PNG para compartir. Si el navegador no permite compartir archivos,
  descarga la imagen para adjuntarla manualmente. No envía mensajes automáticamente.
- Nombre a todo el ancho, barra de guardado compacta y acciones de eliminación
  en “Más opciones”. Indicadores secundarios disponibles en el inicio desplegable.

## Persistencia

Los borradores son locales al navegador y están aislados por usuario y workspace.
“Guardar cambios” sincroniza producto, foto, impresiones y colores mediante una
sola transacción de `save_product_bundle_v2`. Los parámetros generales usan el
guardado independiente existente. No hay sincronización de borradores entre dispositivos.

## Base de datos

Migración aplicada: `20261015235940_kultiapp_v12_multicolor_photo_bundle`.
Agrega `products.photo_data`, `print_jobs.filaments` y la RPC V2, manteniendo la
RPC original para clientes anteriores. La RPC V2 es SECURITY INVOKER; conserva
RLS y comprueba permisos del workspace. No se crearon buckets públicos.

Se verificó con una transacción autenticada que 100 g + 10 g de purga a
$16.000/kg y 50 g + 5 g de purga a $20.000/kg generan 165 g y $2.860.
El producto de prueba fue revertido con ROLLBACK. También se verificó el
rechazo de gramos negativos y que el fallo no alterara el guardado anterior.

El asesor de seguridad no informó problemas nuevos de tablas/RLS. Permanece
la advertencia de protección de contraseñas filtradas desactivada en Auth;
revisar disponibilidad/configuración en Supabase antes de habilitarla.

## Pruebas locales

Dependencia de prueba, no de producción: `jsdom@26.1.0`.

```sh
npm install --prefix /tmp/kulti-test jsdom@26.1.0 --no-audit --no-fund
NODE_PATH=/tmp/kulti-test/node_modules node tests/v12.test.cjs
node --check app.js
git diff --check
```

Las pruebas usan un backend simulado y no escriben en Supabase. Cubren
multicolor, purga, duplicación, límite de siete, borradores, guardados exitosos
y fallidos, permisos de lectura, fotos y privacidad de la cotización.
