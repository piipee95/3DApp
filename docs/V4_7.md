# KultiApp V4.7 · Materiales del pedido según el producto

En «Materiales y stock» de cada pedido (con producto, no vendido desde stock) aparece **«Usar materiales actuales del producto»**: reemplaza la lista por la receta actual aunque el costo no haya cambiado (por ejemplo, pedidos creados antes de vincular los filamentos). Usa `refresh_order_materials` (V4.6): la reserva o el consumo se ajustan por la diferencia.

Test: `tests/v47.test.cjs`.
