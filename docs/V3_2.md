# KultiApp V3.2 — Páginas públicas y versión visible

## Seguimiento del pedido (para el cliente)
- En cada pedido de cliente: botón «Seguimiento» → «Crear enlace de seguimiento».
- El enlace (`/seguimiento.html#token`) es privado: 64 caracteres al azar, imposible de adivinar.
- El cliente ve el estado en pasos, la fecha estimada, el total, lo pagado y el saldo, más las fotos del trabajo terminado. No ve costos, utilidad, notas internas ni datos de otros pedidos.
- Se envía por WhatsApp con el mensaje ya escrito. «Desactivar enlace» lo corta al instante.

## Catálogo público
- Productos → «Catálogo»: se elige la dirección (`/catalogo.html?c=kultiverso-pop`), el WhatsApp, una presentación y qué productos publicar con su precio público.
- El precio parte del precio de venta. Si se deja vacío, se muestra «Precio a consultar».
- Cada producto muestra foto, precio, «Disponible» o «Por encargo», y un botón «Lo quiero» que abre WhatsApp con el producto escrito.
- Las fotos solo se pueden leer sin sesión si el producto está publicado (o si es una foto de un pedido con seguimiento activo).

## Versión
- La versión de la app aparece en el menú (escritorio: abajo, junto a «Powered by ELARA»; celular: menú de cuenta) y en el inicio de sesión.
- Debe coincidir con `CACHE` de `sw.js`; una prueba lo verifica.

Base de datos: `docs/SCHEMA_V32.sql` (migración `kultiapp_v32_public_pages`, ya aplicada).
