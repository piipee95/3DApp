# V2.3 — Archivos originales del cliente

## Uso

En Más / menú lateral → Archivos del cliente → Crear enlace de carga. También desde el detalle de un pedido → Pedir fotos al cliente, para asociar la solicitud a ese pedido.

Cada enlace vence **48 horas después de crearlo**, calculadas en el servidor. Admite **un envío**, de hasta 5 fotos de 50 MiB cada una. Al confirmar el envío queda cerrado; no vuelve a permitir cargas. Puede desactivarse antes desde la app. Caducar/cerrar el enlace no elimina los archivos recibidos.

El cliente abre `subir.html#<token>`, sin cuenta ni correo obligatorio. Ingresa su nombre, elige originales y puede agregar indicaciones. Formatos: JPG/JPEG, PNG, HEIC/HEIF, WebP, AVIF, TIFF/TIF, BMP y GIF. Se envía el mismo objeto File sin transformación: conserva sus bytes, dimensiones, calidad y metadatos. No se ejecuta optimizePhoto ni conversión de imagen. El aviso pide enviar originales desde Fotos/Archivos y evitar reenvíos comprimidos o capturas cuando exista el original.

En el plan actual el máximo de Storage por archivo es 50 MB. No es una carga ilimitada: se aplican cuotas de almacenamiento del proyecto. Las vistas previas se ofrecen para JPG, PNG y WebP; otros formatos se descargan como originales para abrirlos en software compatible.

## Privacidad e integridad

- Bucket `customer-originals` privado, separado del catálogo. No se modifica `product-photos`.
- Token de solicitud aleatorio de 256 bits, transmitido en fragmento URL (no en referer/consulta HTTP). No hay listado público de solicitudes ni archivos.
- La RPC valida token, vencimiento, cierre, formato, tamaño y límite de cupos bajo bloqueo de fila; cada ruta de carga tiene una capacidad aleatoria independiente. La subida solo permite INSERT, sin reemplazar ni leer otros archivos.
- Finalizar valida presencia y metadatos del objeto. Completar cierra el enlace en servidor. Reintentos pueden reconciliar una subida completada antes de perder conexión.
- Miembros del equipo pueden leer archivos; solo editor/propietario crea o desactiva solicitudes. Las descargas usan sesión y las vistas previas URLs firmadas de 5 minutos.
- Badge de solicitudes recibidas sin revisar en la navegación; se actualiza al abrir/reingresar a la sección. No se envían avisos externos automáticos.
- Hasta 100 solicitudes recientes visibles. Archivos cargados a medias/cupos pendientes no se ofrecen como recibidos; si el cliente agota los 5 cupos debe solicitar otro enlace.
