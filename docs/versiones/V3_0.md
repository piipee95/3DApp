# KultiApp V3.0 — Precios rápidos para personalizados

- **Productos → «Precios rápidos»**: tablas con un nombre (p. ej. «Cuadro personalizado»), tamaños o
  versiones con su precio y extras opcionales (luz LED, nombre grabado…), con IVA incluido o no.
  Se pueden desactivar o eliminar sin afectar cotizaciones ni pedidos ya creados.
- En **Nueva cotización** y **Nuevo pedido**: «Precio desde tabla» → eliges tamaño y extras y se
  completan el precio por unidad, el IVA y el nombre del trabajo («Cuadro personalizado 30×40 + Luz LED»).
  Si escribes el nombre a mano, se respeta al cambiar opciones. El precio sigue siendo editable.
- Base de datos: migración `kultiapp_v30_price_lists` (referencia `docs/SCHEMA_V30.sql`); el respaldo
  incluye las tablas. Código: `js/20-price-lists.js`.

Pruebas: `tests/v30.test.cjs`.
