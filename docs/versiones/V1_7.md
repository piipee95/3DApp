# KultiApp V1.7 — Stock de producto, fabricación y selector de filamento

## Qué cambia

- **Dos tipos de pedido**
  - *Pedido de cliente* (con cliente, precio y cotización). Si el producto tiene unidades
    terminadas, se puede marcar **Entregar desde stock**: no reserva materiales y descuenta
    unidades al quedar listo o entregado.
  - *Fabricar para stock* (Resumen del producto → «Fabricar para stock»). Reserva materiales
    y, al pasar a «Listo», descuenta el filamento y suma las unidades al stock del producto.
    Con **Ya está fabricado** se registra de inmediato (sirve para cargar lo que ya está hecho).
- **Stock del producto**: tarjeta en Resumen (disponible / reservado), columna Stock en la
  lista de productos y **Ajustar conteo** con historial de movimientos (fabricación, venta, ajuste).
- **Precio y stock** desde el menú ⋯ de cada producto: precio final (vacío = automático),
  margen objetivo y stock real con vista previa del margen.
- **Selector de filamento**: al agregar un color se abre una grilla con color, marca, $/kg y
  gramos disponibles (rojo si no alcanza). Los colores vinculados muestran una ficha compacta.
- Pedidos: filtro «Fabricación»; las fabricaciones no cuentan como ventas en Inicio.

## Base de datos

Migraciones `kultiapp_v17_product_stock` y `kultiapp_v17_adjust_stock_invoker`
(referencia en `docs/SCHEMA_V16.sql`). El stock solo cambia mediante triggers de pedidos y
la función `adjust_product_stock`; la API no puede editar las columnas directamente.
