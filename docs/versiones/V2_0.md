# KultiApp V2.0 — Abonos, saldos y WhatsApp

## Pagos por pedido

- Cada pedido de cliente muestra **Total, Pagado y Saldo** con barra de avance y estado
  (Sin pago / Abonado / Pagado). Las fabricaciones para stock y los pedidos cancelados no generan saldo.
- **Registrar pago**: monto (atajos 50% y saldo completo), medio (transferencia, efectivo, tarjeta, otro),
  fecha y nota. Los pagos se pueden eliminar si se registraron por error.
- **Abono inicial** opcional al crear un pedido o al convertir una cotización aceptada.
- Inicio: indicador **Por cobrar** con acceso al filtro; Pedidos: filtro «Por cobrar» y saldo en cada fila;
  Clientes: deuda por cliente.

## WhatsApp

- Cotización: botón **WhatsApp** que guarda la cotización y abre el chat del cliente con un resumen
  (folio, producto, total, vigencia y plazo). «Compartir» envía además la imagen con ese texto.
- Pedido: mensajes listos para **Pedido listo**, **Recordar saldo** y **Confirmar pago**.
- Usa el teléfono del cliente guardado (números chilenos de 9 dígitos se completan con +56); si no hay,
  WhatsApp pide elegir el contacto.

## Base de datos

Migración `kultiapp_v20_order_payments` (referencia en `docs/SCHEMA_V20.sql`): tabla `order_payments`
con RLS por equipo; solo editores registran o eliminan pagos.
