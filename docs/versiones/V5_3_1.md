# V5.3.1 — Editor de estudio

El editor conserva las cuatro pestañas y todos sus campos. En escritorio ancho, costo, precio y guardado permanecen en un panel lateral; en móvil siguen en una barra inferior. Las acciones destructivas quedan separadas del guardado. La cabecera móvil se mantiene en una fila con el nombre abreviado visualmente.

Se agrupan estado de guardado y descarte; al guardar se muestra un estado visual propio, sin heredar el color del estado anterior. El resumen financiero usa una superficie limpia, tipografía numérica y acento de marca. No se modifica persistencia, RPC, datos, fórmulas ni reglas de stock.

Validación: ESLint y 43 suites en Node 24.22.1 / TZ=UTC, con backend simulado. Navegador local: Producto claro de escritorio y Resumen oscuro en contenedor de 390 px, con datos ficticios. No se realizaron guardados contra datos reales ni prueba física iPhone.
