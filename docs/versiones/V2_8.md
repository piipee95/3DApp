# KultiApp V2.8 — Código dividido en archivos

`app.js` (≈8.100 líneas) se dividió en archivos por sección dentro de `js/`, sin cambiar ninguna línea
de lógica (la unión de los archivos es idéntica al `app.js` anterior):

| Archivo | Contenido |
|---|---|
| `supabase-client.js` | Carga el SDK de Supabase (módulo) |
| `01-core.js` | Estado, inicio de sesión, equipo, ajustes, registro de errores |
| `02-products.js` | Lista de productos, editor y guardado |
| `03-app-shell-drafts.js` | Render, campos, pestañas del editor y borradores |
| `04-photos-filaments.js` | Fotos de productos y filamentos por color |
| `05-orders.js` | Recursos, pedidos, carga reciente, nuevo pedido y detalle |
| `06-quote-document.js` | Documento de cotización (vista, PDF e imagen) |
| `07-inventory.js` | Inventario, recetas de materiales, contraseñas |
| `08-product-stock.js` | Stock de producto, edición rápida, selector de filamento |
| `09-quotes-customers.js` | Cotizaciones guardadas, clientes y pantalla recordada |
| `10-search-install.js` | Búsqueda global y app instalable |
| `11-payments-whatsapp.js` | Pagos, saldos y WhatsApp |
| `12-reports-backup.js` | Reportes, Excel y respaldo |
| `13-loading-editor.js` | Indicadores de carga y mejoras del editor |
| `14-quick-create.js` | Menú «Nuevo», pedidos/cotizaciones a medida, vincular producto |
| `15-shell-navigation.js` | Íconos, navegación, encabezado, avisos y diálogos |
| `16-home.js` | Inicio |
| `17-lists.js` | Vistas de Pedidos, Inventario e Impresoras |
| `18-customer-files.js` | Archivos de clientes |
| `19-start.js` | Arranque (`init()`) |

- Los archivos son scripts clásicos que comparten un ámbito global y se ejecutan en el orden de
  `index.html` (el módulo del SDK primero). Ningún archivo ejecuta lógica al cargarse salvo registrar
  eventos, por lo que el orden solo importa para `19-start.js`, que va al final.
- `sw.js` guarda todos los archivos para abrir sin conexión (caché `kultiapp-v28`).
- Las pruebas leen el orden desde `index.html`. Se verificó además la app real en el navegador con los
  archivos separados recorriendo todas las secciones, sin errores.
