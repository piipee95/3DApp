# V3.1.1 — Referencia Create UI y originales del cliente

Revisión 24/10/2026 sobre main V3.1 c5f8245, sin reconstruir ni migrar de framework.

## Licencias y compatibilidad

Fuentes oficiales verificadas:
- https://createui.co/docs/installation — requiere React y Tailwind v4.
- https://createui.co/legal/license — B1 permite la biblioteca gratuita bajo licencia tipo MIT; B2 es de pago.
- https://github.com/createui/createui-components/blob/main/LICENSE — MIT del repositorio público; no autoriza componentes Pro.
- https://createui.co/docs/components/file-upload — File Upload es Pro y Dropzone es gratuito.

Decisión: no instalar ni copiar código de Create UI. Se usa exclusivamente como referencia de patrones. Dropzone, lista de archivos, acciones y confirmación se implementan con HTML/DOM nativos y estilos propios de KultiApp (sin paquetes, iconos ni recursos externos nuevos). La alternativa propia sustituye File Upload Pro, sin costo ni licencia de terceros adicional. Se preserva el diseño existente de Claude: filas, filtros, menús, tipografía y colores.

## Cambios

Formulario público: arrastrar/soltar, nombre y peso de cada original, aviso por formato/tamaño inválido y quitar selecciones antes de subir. El botón de envío se distingue explícitamente de Quitar. Se bloquea cambiar selección/nombre/nota una vez reservados los cupos, para que el reintento conserve los mismos originales. Estados Enviando y Confirmando recepción sin fingir progreso en bytes.

Solicitudes: se conservan archivar, restaurar, eliminar con confirmación, borrado reintentable y permisos editor/propietario. Agrupador Activos/Archivados usa semántica de botones con aria-pressed (no un tablist incompleto).

Se conservan originales sin conversión, 5 archivos, 50 MiB por archivo, JPG/JPEG, PNG, HEIC/HEIF, WebP, AVIF, TIFF, BMP, GIF; 48 horas desde creación y cierre al completar un envío. No se cambian SQL ni datos de clientes.
