# KultiApp V4.6 · Pedidos con los materiales actuales del producto

«Actualizar costo y materiales» (en el pedido, o al guardar el producto) ahora también reemplaza el listado de materiales del pedido por la receta actual del producto:

- **Reservado**: se libera la reserva anterior y se reserva la receta nueva (revisa stock).
- **Consumo registrado**: el stock se mueve solo por la diferencia (consumo extra o devolución del sobrante) y el costo real se ajusta.
- **Sin materiales**: se reserva la receta ahora (y se consume si el pedido ya está listo).

Las ventas desde stock no usan materiales: solo cambia su costo. Base de datos: `refresh_order_materials` (docs/SCHEMA_V46.sql). Test: `tests/v46.test.cjs`.
